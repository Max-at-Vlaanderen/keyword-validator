# Keyword validator

Streamlit interface for reviewing the keywords generated by the experiment.

## Data files

An administrator can upload `keyword_extraction_review.xlsx` from the app's
sidebar. The upload reads the `result` sheet and expects these columns:

- `record_identifier`, `title`, and `abstract` (displayed as fixed source data)
- `subject_label`, `keyword_matcher_output`, and `concept_label` (reviewed in separate lists)

At first import, the workbook is copied to `data/keyword_extraction_review.csv`
for future local use. Review decisions are saved in
`data/keyword_validations.csv`; both are ignored by Git.

## Administrator import

Set a strong administrator password before starting the app. For local use,
put it in `.streamlit/secrets.toml`:

```toml
admin_password = "replace-with-a-strong-password"
```

For a deployment environment, set:

```text
KEYWORD_VALIDATOR_ADMIN_PASSWORD=replace-with-a-strong-password
```

Only a user who enters this password in the sidebar can upload and replace the
source workbook. The workbook is validated before it is written to disk. The
local CSV copy is refreshed and existing saved reviews remain available for
matching record identifiers.

The same administrator section can refresh the SoilVoc vocabulary from its
public source. The locally stored labels become options in the **New keywords
from SoilVoc** list for each record. The downloaded Turtle file and derived CSV
index are local-only and ignored by Git.

## Run

```text
uv run streamlit run app_validator.py
```
